# 📺 PlaylistCheck

[![Update: Manual](https://img.shields.io/badge/Update-Manual-blue.svg)]()

একটি স্মার্ট IPTV প্লেলিস্ট জেনারেটর এবং লিংক চেকার। এই রিপোজিটরিটি `channels.txt` ফাইল থেকে লাইভ চ্যানেলগুলোর ডেটা (নাম, লোগো, ক্যাটাগরি এবং লিংক) প্রসেস করে ব্যবহারযোগ্য একটি ফ্রেশ `combined_playlist.m3u` ফাইল তৈরি করে।

---

## ✨ বৈশিষ্ট্য (Features)

*   🎨 **লোগো ও ক্যাটাগরি:** প্রতিটি চ্যানেলের জন্য নিজস্ব লোগো এবং নির্দিষ্ট গ্রুপ/ক্যাটাগরি (যেমন- Sports, Entertainment, News) সাপোর্ট করে। 
*   🔍 **লিংক ভ্যালিডেশন:** পাইথন স্ক্রিপ্টের মাধ্যমে সচল এবং ডেড লিংকগুলো চেক করে সহজেই ফিল্টার করা যায়।
*   🚀 **সর্বজনীন সামঞ্জস্য:** তৈরি হওয়া `.m3u` প্লেলিস্টটি যেকোনো জনপ্রিয় IPTV প্লেয়ারে (যেমন- VLC, OTT Navigator, Tivimate, MX Player) সরাসরি ব্যবহার করা যায়।

---

## 🚀 যেভাবে ব্যবহার করবেন (How to Use)

আপনার প্রিয় IPTV প্লেয়ারে খুব সহজেই নিচের পদ্ধতি ব্যবহার করে প্লেলিস্টটি যুক্ত করতে পারেন:

### 🌐 লাইভ নেটওয়ার্ক URL (সবচেয়ে কার্যকরী)
সবচেয়ে ভালো অভিজ্ঞতার জন্য সরাসরি নিচের লিংকটি কপি করে আপনার প্লেয়ারের **M3U URL** বা **Playlist Link** বক্সে পেস্ট করুন। এর ফলে প্লেলিস্টে নতুন কোনো চ্যানেল বা লোগো আপডেট করা হলে, আপনার প্লেয়ারেও তা পেয়ে যাবেন।
